# 📊 Retail Sales Dashboard

An interactive **Retail Sales Dashboard** built in **Microsoft Excel** to analyze sales performance, customer behavior, product trends, and store-wise performance. The dashboard transforms raw retail data into meaningful business insights using Pivot Tables, Pivot Charts, Slicers, and KPIs.

---

## 🚀 Project Overview

This dashboard helps retailers monitor their sales performance across multiple stores, products, suppliers, and customers. It provides an easy-to-understand visual representation of business metrics to support data-driven decision-making.

## ⚙️ How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel (2019 or later).
3. Navigate to the **Dashboard** worksheet.
4. Use the slicers to filter data.
5. Explore charts and KPIs for business insights.
